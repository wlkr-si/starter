# Starter working rules

Use the committed npm lockfile with Node.js 24+. Run `npm ci` and `npm run verify`.
Keep this a static, account-free local starter with no host bindings, telemetry,
secrets, production defaults or hosted Actions.

Edit `src/site.ts`, the page and app-owned layout/styles to compose the demo.
Preserve installed WLKR and stock shadcn component/hook source and all upstream
notices. Use the pinned official CLI and review source/provenance changes for a
registry refresh. Do not silently rewrite vendor files or update their hashes.

Check phone, keyboard, light/dark, clipboard failure and reduced motion in a real
browser. Report audit scope and unresolved findings. Outside adopters must remove
the studio endorsement; names and marks are excluded from MIT.
